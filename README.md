# Angular_FinalProject_backend

# Final Project Backend API

ระบบ Backend API สำหรับจัดการข้อมูลลูกค้า (Customer) และรายการสั่งซื้อ (Order) พร้อมรองรับระบบค้นหาพิกัดตำแหน่ง (Geospatial Query) 

## Base URL
`https://vercel.app`

---

## 1. Customer API (ระบบจัดการข้อมูลลูกค้า)

### 🔹 ดึงข้อมูลลูกค้า / ค้นหาลูกค้า
* **URL:** `/api/customer`
* **Method:** `GET`
* **Query Parameters (ตัวเลือกเสริม):**
  * `name=ข้อความ` : ค้นหาลูกค้าด้วยชื่อ
  * `limit=ตัวเลข` : จำกัดจำนวนข้อมูลลูกค้าที่ดึงขึ้นมา
  * `lat=พิกัด&lng=พิกัด` : ค้นหาลูกค้าทั้งหมดใน**ระยะ 1 กิโลเมตร** จากพิกัดที่กำหนด (ต้องส่งพร้อมกันทั้งคู่)
* **ตัวอย่างการใช้งาน:** `/api/customer?lat=16.2634&lng=103.27`

### 🔹 ดึงข้อมูลลูกค้าผ่านไอดี
* **URL:** `/api/customer/:id`
* **Method:** `GET`
* **ตัวอย่างการใช้งาน:** `/api/customer/5`

### 🔹 เพิ่มข้อมูลลูกค้าใหม่
* **URL:** `/api/customer`
* **Method:** `POST`
* **Request Body (JSON):**
  ```json
  {
    "customer_name": "คุณสมชาย ใจดี (ย้ายห้อง)",
    "phone_number": "0812345678",
    "location_name": "คอนโดหน้า มมส ตึก B ชั้น 5",
    "latitude": 16.248900,
    "longitude": 103.253500
  }
  ```

### 🔹 แก้ไขข้อมูลลูกค้า
* **URL:** `/api/customer/:id`
* **Method:** `PUT`
* **Request Body (JSON):** ส่งชุดข้อมูลที่ต้องการแก้ไขในรูปแบบเดียวกับตอน `POST`

### 🔹 ลบข้อมูลลูกค้า
* **URL:** `/api/customer/:id`
* **Method:** `DELETE`

## 2. Order API (ระบบจัดการรายการสั่งซื้อ)

### 🔹 ดึงข้อมูลรายการสั่งซื้อ
* **URL:** `/api/order`
* **Method:** `GET`
* **Query Parameters (ตัวเลือกเสริม):**
  * `limit=ตัวเลข` : จำกัดจำนวนรายการสั่งซื้อที่ดึงขึ้นมา
  * `lat=พิกัด&lng=พิกัด` : ค้นหารายการสั่งซื้อทั้งหมดใน**ระยะ 2 กิโลเมตร** จากพิกัดที่กำหนด (ต้องส่งพร้อมกันทั้งคู่)
* **ตัวอย่างการใช้งาน:** `/api/order?limit=10`

### 🔹 ดึงข้อมูลรายการสั่งซื้อผ่านไอดี
* **URL:** `/api/order/:id`
* **Method:** `GET`
* **ตัวอย่างการใช้งาน:** `/api/order/1062`

### 🔹 เพิ่มข้อมูลรายการสั่งซื้อใหม่
* **URL:** `/api/order`
* **Method:** `POST`
* **Request Body (JSON):**
  ```json
  {
    "customer_id": 1,
    "box_count": 3,
    "order_note": "ขอช้อนส้อมเพิ่มด้วยครับ และแยกพริกน้ำปลา"
  }
  ```

### 🔹 จำลองข้อมูลรายการสั่งซื้อเข้าสู่ระบบ (Mock Data)
* **URL:** `/api/order/test`
* **Method:** `POST`
* **คำอธิบาย:** ระบบจะทำการล้างข้อมูลทั้งหมดในฐานข้อมูล และจำลองรายการสั่งซื้อชุดใหม่ลงไปประมาณ 20-30 รายการโดยอัตโนมัติ (ไม่ต้องส่ง Request Body)

### 🔹 แก้ไขข้อมูลรายการสั่งซื้อ
* **URL:** `/api/order/:id`
* **Method:** `PUT`
* **Request Body (JSON):**
  ```json
  {
    "box_count": 3,
    "order_note": "เปลี่ยนเป็นไม่ใส่ผักโรยหน้า",
    "status": "shipping"
  }
  ```

### 🔹 ลบข้อมูลรายการสั่งซื้อ
* **URL:** `/api/order/:id`
* **Method:** `DELETE`

### 🔹 ล้างข้อมูลรายการสั่งซื้อทั้งหมด
* **URL:** `/api/order/clear`
* **Method:** `DELETE`
* **คำอธิบาย:** ลบรายการสั่งซื้อทั้งหมดออกจากฐานข้อมูลทันที
